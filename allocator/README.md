# allocator

Copies of [Allocator](https://github.com/endurodave/Allocator) 1.2.0 and [xallocator](https://github.com/endurodave/xallocator) 1.3.0 (their `src/` folders), built by this repository's CMake demo. `StateMachine.h` can route event data through xallocator (see its `XALLOCATOR` comment).

The PlatformIO and Arduino packages don't include them.
